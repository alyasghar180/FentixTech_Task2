# Catchhub Landing Page

A professional, pixel-perfect landing page for the Catchhub social communication app. Built with pure HTML5 and CSS3, featuring a fully responsive design that works seamlessly across desktop, tablet, and mobile devices.

## Project Overview

Catchhub is a social platform that combines video streaming, messaging, and channel creation. This landing page showcases the app's key features through an engaging, modern design.

**Core Features:**
- Watch and stream content
- Communicate through channels and messages
- Create your own entertainment or business channels
- Professional group chat functionality

## Design Details

### Typography
- **Font Family**: System fonts (-apple-system, BlinkMacSystemFont, Segoe UI, Roboto)
- **Hero Title**: 48px, 700 weight, 1px letter-spacing
- **Section Titles**: 42px, 700 weight, 2px letter-spacing
- **Body Text**: 16px, 1.6 line-height
- **Responsive Scaling**: Titles reduce proportionally on smaller screens

### Color Palette
- **Primary Text**: #222 (dark gray)
- **Secondary Text**: #333 (darker gray)
- **Tertiary Text**: #666, #888 (medium gray)
- **Accent**: #00a8e8 (light blue)
- **Backgrounds**: #fff, #f5f5f5, #fafafa (whites and light grays)

### Spacing
- **Section Padding**: 100px (desktop) → 30px (mobile)
- **Gap Between Elements**: 80px (desktop) → 30px (mobile)
- **Button Gap**: 16px (desktop) → 12px (mobile)
